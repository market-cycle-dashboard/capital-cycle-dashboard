模型会把 Fed 资产、TGA、RRP、准备金、美元指数与 SOFR-IORB 合成成一张可跟踪的流动性仪表盘。

    美元流动性管道地图

    从中央银行资产负债表到全球资产价格
    1. Fed 资产端：RMP / QE / 回购等待数据

    2026 年重点是 RMP：Fed 买入短期国债以匹配准备金趋势需求，性质更像管道维护，不等同于主动 QE。

    2. TGA：财政部现金账户等待数据

    TGA 上升像抽水，财政部把市场现金吸回 Fed；TGA 下降像放水，财政支出重新进入银行体系。

    3. ON RRP：缓冲垫耗尽等待数据

    RRP 曾在 2022-2023 年承担蓄水池功能；2026 年余额接近零后，更多是历史缓冲参考，不再是主要保护垫。

    4. 银行准备金：风险资产底层余额等待数据

    准备金充裕时融资价格稳定；接近稀缺区间后，SOFR、回购利率和信用利差会更敏感。

    5. Eurodollar：FX Swap / 基差等待数据

    离岸美元不是只看 DXY，而是看非美机构通过 FX swap 合成美元时，要为偏离 CIP 支付多少额外成本。

    6. SRF / SOFR-IORB：常规压力阀等待数据

    SRF 使用不再只意味着危机；SOFR-IORB 上穿和 SRF 频繁使用，说明准备金进入“够用但边际变贵”。

    当前版本接入 FRED：Fed 资产、TGA、ON RRP、准备金、SOFR、IORB 与广义美元指数。模型权重已从“水量模型”改为“水位 + 融资价格 + 缓冲垫风险”：准备金与净流动性为核心，RRP 作为枯竭风险开关，SOFR-IORB 权重上调。Eurodollar 基差目前只展示，不参与总分。

    交叉货币基差是什么

    在无摩擦世界里，直接借美元与“借欧元/日元 + FX swap 换成美元”的成本应该一致，这就是 covered interest parity（CIP）。现实中这个等式经常失效，失效的残差就是 cross-currency basis。

    合成美元成本 = 本币利率 + FX forward 隐含成本 + cross-currency basis

    当 EUR/USD 或 JPY/USD 基差更负时，通常意味着非美机构通过 swap 借美元更贵，美元短缺或交易商资产负债表更稀缺。

    它在模型里体现在哪

    当前仪表盘尚未直接接入可用的基差序列，所以“离岸美元”只以广义美元指数和 SOFR-IORB 作代理：DXY 表示美元价格压力，SOFR-IORB 表示境内抵押融资堵点。它们不能替代基差，只能提示压力可能存在；真正的基差读数当前只展示授权状态，暂不参与模型总分。

    当前代理：Offshore USD Proxy = DXY momentum + SOFR-IORB + RRP 枯竭

    升级后应使用 3M EUR/USD basis、3M JPY/USD basis、FX swap implied USD rate 和 SRF 使用量，构成真正的海外美元压力分。

    海外美元派生怎么定义

    海外美元派生不是 Fed 直接投放准备金，而是美国境外银行、企业、基金和央行通过美元存款、美元贷款、商业票据、FX swap、cross-currency swap 创造出的美元债权债务链。

    Eurodollar 派生 = 非美资产负债表上的美元负债扩张 + 衍生品合成美元融资

    这套美元没有完整对应的 Fed 准备金支持，平时依靠银行资产负债表和 swap 市场滚动；压力期则体现在基差走阔、美元融资期限缩短、央行互换线或 FIMA/SRF 需求上升。

    读数规则

    如果 DXY 上行但基差不走阔，更多是汇率或利差驱动；如果 DXY 平稳但基差突然更负，说明真正的离岸融资管道在变贵；如果基差、SOFR-IORB、SRF 同时恶化，则说明境内外美元压力共振。

    真正的红灯：basis 更负 + SOFR-IORB 上穿 + SRF 频繁使用 + 信用利差走阔

    所以 Eurodollar 在模型中的角色，是“海外美元影子信用的价格阀”，不是 Fed 净流动性公式里的一个简单水桶。

    研究动作

    把流动性状态转成投研问题

    看 RMP 与 TGA

    QT 结束后，总闸门不再只看缩表，要看 RMP 购买能否抵消 TGA 回补、发债和准备金趋势需求。

    看 SRF 与堵点价格

    观察 SOFR-IORB、SRF 使用、回购利率和信用利差，判断压力是在银行、交易商还是抵押品市场。

    看资产映射

    宽松扩散偏利好高久期成长；抽水收缩偏利好现金流确定、低杠杆、低估值资产。

    看离岸美元与关税

    贸易摩擦会让 FX swap、美元基差和非美银行融资成本独立收紧，这条线需要和货币政策管道分开观察。

    A股温差分析

    ETF、两融、成交活跃度、基金集中度与红利价值吸引盆

    不是看全市场水位，而是看热量停在哪里。

    A股内部流动性更像温度场：ETF 和两融提供边际水量，成交活跃度决定传导速度，基金集中度决定抱团惯性。这个框架把结构行情拆成科技成长、消费/茅系、小盘扩散、新能源与红利价值五类吸引盆。

    基金集中度前十约 69%样本基金前十重仓集中度仍高，说明抱团惯性还在；主线转弱时更可能先内部切换，而不是平滑扩散。

    1. 判断吸引盆稳定性

    红区只是历史常见状态，不等于安全。真正稳定要同时看温度、拥挤度、ETF 流入和融资温度是否共振。

    稳定 = 温度高但不过热 + ETF 承接稳定 + 杠杆不极端

    2. 判断热量外溢

    小盘扩散升温代表风险偏好扩散，红利价值升温代表防御资金接力。两者同时升温，才说明市场不再只围绕科技单一吸引盆。

    外溢 = 科技降温不崩 + 小盘/红利成交温度上行

    3. 判断抱团瓦解

    若科技高温、ETF 成交占比高、主力净流出扩大，同时基金集中度仍高，说明不是扩散，而可能是拥挤交易的边际松动。

    瓦解风险 = 高温 + 高占比 + 净流出 + 集中度高
