# 投研站点蓝图

## 站点定位

这个项目不是单一图表页，而是一个可复用、可扩展、可推广的投研站点。它的目标是把分散的研究框架、数据图表、深度报告和方法论沉淀成一个长期维护的研究工作台。

站点要同时服务三类场景：

- 自己复盘：快速回到核心框架，更新结论，记录判断变化。
- 对外展示：让别人能在短时间内理解研究体系，而不只是看到某张图。
- 模块扩展：每新增一个研究主题，都能放进一致的导航、页面和数据结构里。

## 三层结构

### 1. 站点层

站点层回答“这个投研系统是什么”。它负责提供总览、导航、模块状态和最近更新。

建议包含：

- 总览 Dashboard
- 研究框架入口
- 深度报告入口
- 数据中心入口
- 方法论入口
- 更新记录

### 2. 模块层

模块层回答“某个研究框架如何帮助决策”。每个模块都是一个可以独立完善的房间。

暂定模块：

- 资本周期
- 流动性
- 估值盈利
- 市场脉冲
- 深度报告
- 行业地图
- 组合跟踪

每个模块都应使用统一结构：

- 研究问题
- 当前结论
- 核心图表
- 筛选与交互
- 详情面板
- 研究池或候选列表
- 方法论
- 更新记录

### 3. 组件层

组件层回答“哪些工具可以复用”。组件应该为多个模块共享，而不是为单个页面临时堆出来。

可复用组件包括：

- 模块卡片
- 指标卡片
- 筛选器
- 图表容器
- 详情面板
- 表格
- 研究池列表
- 报告卡片
- 方法论说明块
- 更新时间标识
