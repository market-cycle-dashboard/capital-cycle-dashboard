## 今天学到的东西

1. 投研站点的内容不是“文章仓库”，而是“研究对象的状态机”

泡泡玛特这篇报告发布后，真正暴露的问题不是报告够不够长，而是用户怎么再次进入、怎么分享、怎么刷新、怎么回到同一个研究状态。投资研究站点如果不能把“我正在读哪家公司、哪篇报告、哪个判断”稳定保存下来，就会像一个展示页，而不是工作台。

2. 报告模块需要把“摘要卡片”和“完整文章”当作两个不同产品

卡片解决扫描问题：我为什么要读、结论是什么、置信度如何。

正文解决判断问题：证据链、估值纪律、风险排除、可跟踪指标。

今天泡泡玛特报告在这两层之间已经打通，但未来应该让二者更有结构关系：卡片不是正文的压缩，而是投委会备忘录；正文则是尽调底稿。

3. 深链是投研产品的基础设施，不是小功能

一个好链接应该像研究笔记里的坐标。别人点开时，应该直接到达“这条判断”，而不是被带到站点大厅再自己找路。今天这个 bug 很小，但它暴露了一个重要原则：所有研究对象都应该有稳定 URL。

## 冒出来的灵感

1. 给每篇报告生成“投资备忘录卡”

每篇深度报告顶部可以自动生成一个固定结构：

- 核心判断
- 当前价格区间
- 不买的理由
- 买入条件
- 触发重新评估的信号
- 半年跟踪指标

这会让站点更像投资工作台，而不是文章集。

2. 报告详情页应该有“研究状态栏”

例如：

- 状态：跟踪中 / 等待价格 / 重新评估 / 已失效
- 最近复核日期
- 下次复核触发条件
- 核心变量是否变化

泡泡玛特适合标成：“好公司，等待更好价格；重点观察 THE MONSTERS 占比与非 THE MONSTERS IP 接棒。”

3. 建立“公司报告 v5 质检器”

今天用户明确要求“七大模块是否都囊括过或思考过”。这可以产品化：写完一篇报告后，自动检查是否覆盖：

- 管理层六/七维评价
- 竞争对手财务对照
- R/N/g 拆解
- AV/EPV/成长价值
- 股东权益回报率与分红回本
- 风险是否真正完成 EPV 冲击测试
- 结论是否区分好公司与好价格

质检器不一定需要 AI，先用清单和关键词也能起步。

4. 报告链接可以进化成语义路由

现在是 `#report-008`。未来可以改成：

- `/reports/popmart`
- `/reports/company/popmart`
- `/reports/popmart#valuation`
- `/reports/popmart#risk`

这样更像知识库，也更利于外部引用。Cloudflare Pages 静态站可以用客户端路由或 `_redirects` 做兼容。
