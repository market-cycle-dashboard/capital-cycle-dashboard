# 公司跟踪报告模板：从原判断到新证据

适用：已完成深度研究后的季报、半年报、年报与重大事件跟踪。跟踪稿围绕原假设裁决，不机械重写公司背景。建议正文 3,000—6,000 字；发生重大估值纠错时增设附录。

## 0. 版本与信息截止

| 字段 | 填写内容 |
|---|---|
| 公司、代码、跟踪期数 | 公司名／交易所代码／01、02…… |
| 原深度报告 | 原文链接、成文日、版本或归档标识 |
| 上一次跟踪报告 | 上期链接和日期；第一次则为空 |
| 本期信息截止 | 截止到哪一天；所用报告是否审计 |
| 年度参考锚 | 最新已披露完整年度；中期增量单列 |
| 价格与资本 | 收盘日期、价格、当日已登记股数、重算市值 |
| 期后事件 | 分红、回购、增发、并购等，注明发生与披露日期 |

冻结原稿，不事后改写先验。发现原文错误，在新稿中更正，并在旧稿显著位置添加更新入口；旧正文作为历史档案保留。

## 1. 第一页先回答三个问题

本期核心裁决：哪些判断加强，哪些削弱，哪些撤回？

研究动作：继续研究／等待／进入价格复核区／退出；若不知道读者持仓，不给出假定其持仓的操作指令。

## 2. 先验台账：原话、阈值和时间都要保留

每家公司优先跟踪 4—6 个能改变价值的命题，不追求覆盖所有科目。

| 假设编号 | 原文及章节 | 原判断日期 | 可观测条件与期限 | 先验信心 | 本期裁决 |
|---|---|---|---|---|---|
| H01 | 原句或忠实摘要 |  | 指标、阈值、口径、期限 | 定性或原文已有概率 | 加强／维持／削弱／证伪／未知 |

裁决规则：加强需要新且有辨别力的证据；维持不等于无条件成立；削弱是竞争解释变得更可信；证伪须触及原命题的失败条件；未知表示披露不足，不能当成零、达标或失败。

历史先验没有数字时，禁止伪造当时的数值概率。如今重建的数值须标注“本期重建／演示假设”。

## 3. 证据台账：最小可审计单元

| 编号 | 事件发生日 | 首次公开日 | 来源及页码 | 新事实 | 支持哪一假设 | 替代解释 | 证据等级 | 相关证据组 |
|---|---|---|---|---|---|---|---|---|
| E01 |  |  | 原始公告链接 | 只写事实 | H01 | 需求／结构／汇率／结算／并表等 | A／B／C／D | G01 |

- A：原始审计数据、交易所公告和已完成资本事件。
- B：未审计财务报告、口径可复算的公司披露。
- C：管理层经营表述、试点指标和未独立验证的经营解释。
- D：访谈、媒体或行业线索，尚不能完整核实。

证据可靠不代表结论强。例如毛利率是可复核事实，毛利率提高源于定价权却只是待验证解释。

以前已经公开的信息，本次补读属于“研究遗漏补正”。同一事实被公告、会议纪要和媒体重复报道，仍算一条证据。将收入、利润、现金的共同驱动归入相关组，避免重复累积信心。

## 4. 三座桥：经营、现金、资本

### 经营桥

列上年全年、上年同期、本期、单季差额和 TTM；不要混合财年、币种和并表口径。

收入拆为地区、产品、量价或渠道；毛利拆为收入与结构；利润拆为毛利、费用、汇兑、一次性收益、税和少数股东。汇兑、减值、重组费用两期对称处理。经常发生的费用不能每次都标为一次性。

Q2＝H1－Q1；Q4＝全年－前三季；TTM＝去年全年－去年同期＋本期。公司披露追溯调整时，两期同步使用重述口径。

### 现金桥

同时列法定经营现金流、TTM 覆盖、资本支出、租赁与股东可分配现金约束。保证金、理财、定期存款和资金占用的加回应两期对称，保持法定值为主列。

应收、存货与预收同时同比和比较年初；期末余额变化不能冒充周转率。附注中的“经营性应付项目”不能自动解释为供应商账款。

### 资本桥

增发：资金和股数同时更新；区分发行净额、实际投入、已形成资产与未来利润。分红：企业价值、持有人总回报和期末股利负债使用一致口径，不重复扣减。库存股、登记注销与仅获批准的注销分开。

## 5. 贝叶斯更新：先定义命题，再决定是否需要数字

推荐正式结论使用定性更新矩阵，并说明为何证据更符合某一种解释。

如有经事前登记且可校准的概率，使用：

后验赔率＝先验赔率×似然比。

后验概率＝先验概率×LR／〔1－先验概率＋先验概率×LR〕。

LR＝P（证据｜假设成立）／P（证据｜假设不成立）。它不是“利好打几分”。相关证据不独立时，使用联合证据包；若无法估计条件依赖，停留在定性判断，不把 LR 生硬连乘。

| 假设 | 新证据包 | 支持的替代解释 | 更新方向 | 如使用数值：依据及敏感性 |
|---|---|---|---|---|
|  |  |  |  |  |

数值全部来自研究者判断时，明确标为演示，不报成客观胜率。必须测试多组先验和 LR。后验不等于股价上涨概率，更不能直接代替仓位或估值。

| 增量回报和成长窗口 |  |  | 竞争与执行证据 |  |  |
| 现金、分红和股数 |  |  | 资本事件 |  |  |

保留四个独立关口：

1. AV：完整列资产折扣、全部负债、少数股东和处置成本，声明方法及局限。
2. EPV：经营利润不等于会计营业利润；厘清财务收益、税、维持支出、租赁、少数股东、超额现金和债务，不重复计量。
3. 成长：以增量资本回报、竞争回应、投入期限与可复制性为依据，低回报扩张不给溢价。
4. 回报：历史股息与未来情景分开；净利润、合并现金流、股东可分配现金不混用。

展示压力、基准和修复情景。将价格区间与触发条件绑定，不机械沿用上期绝对买入价。股价下跌只改变支付价格，不能自动增强经营假设。

## 8. 交付前复核

- 能否用一句话解释本期究竟改了什么，而非只复述业绩？
- 是否保留至少一种反对自己结论的解释？
- 原错误与新证据是否分开？财报公开日与经济事件日期是否分开？
- 核心数字能否从原文和公式复算？是否把所有未知标清？
- 价格、股数、分红、现金、少数股东和租赁是否互相一致？
- 裁决、参数、价格纪律和下一期条件是否一致？

结尾写研究后记：提炼真正的投资问题；反思上期盲点；提取可复用方法；保留公开信息确实无法解决的不足。能在当期核实的不足，应在交付前解决。
